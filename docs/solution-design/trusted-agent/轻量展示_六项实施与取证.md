本轮未发布或升级81、82或其他服务器。先在本地或独立验证环境审核，再按选定范围发布。

建议逐项取证：

## 改动范围与数据边界

前端主要复用聊天、共享审批卡片、收件箱、MCP和安全设置页面。停止提示只解释既有接口返回，不增加轮询或更改取消协议。审批只传递原来的请求ID和范围，展示脱敏对象不回写执行参数。审批URL保留路径以便核对范围，隐藏URL凭据、查询和片段；MCP来源摘要只保留协议、主机和端口。

新后端模块为 `src/qwenpaw/app/routers/security_evidence.py`，由现有全局路由注册，三个接口：

| 方法和路径（统一带 `/api` 前缀） | 行为 |
| --- | --- |
| `GET /security/evidence/protection` | 读取既有脱敏配置和生产保护配置；不输出词库内容、私有路径、主机原值或密钥。 |
| `POST /security/evidence/redaction-check` | 使用固定虚构输入调用现有脱敏函数，不接受自定义检查内容、不调用模型或MCP、不保存测试事件。 |
| `GET /security/evidence/audit` | 使用SQLite URI `mode=ro` 和 `query_only` 读取现有全局治理审计，支持有界筛选和分页。成功响应为 `Cache-Control: no-store`。 |

审计读取没有调用 `AuditLog.get_instance()`，以免读取动作触发现有初始化或旧结构迁移。数据库不存在时不创建文件；旧时间戳结构不迁移、不清空。读取异常返回503，不能伪装为零条成功结果。读取不返回任意 `extra` 或工作目录，命令/代码目标整体隐藏，其他文本隐藏常见凭据及URL敏感部分。CSV单元格防止公式执行。

常见凭据隐藏不是完整的数据分类系统。现场截图前仍应检查业务标识、文件路径和其他未分类信息是否适合出现在材料中。

模型调用、流式响应、工具策略决策、网络策略、Helm、数据库结构、审计清理规则和密钥格式没有调整。原有审批和工具执行机制继续承担实际控制。
