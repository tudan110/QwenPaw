# Portal 六项轻量展示验证

验收页面是「智观 AI」Portal。QwenPaw 提供现有后端接口，验收不需要打开它的管理控制台。首次六项提交 `7cdf5f1e2` 提供了后端取证接口和 QwenPaw 控制台展示；本次补齐 Portal 入口。

| 编号 | Portal 入口 | 操作及预期 |
| --- | --- | --- |
| 301-2 | 统一入口聊天 | 发送长文本请求，出现部分正文后点击停止。已生成正文保留，输入框上方显示时间和后端取消结果。分别核对接受、没有可取消任务、请求失败时的文案；再次发送或切换会话后旧提示应消失。现有聊天审批的「取消任务」成功后也有提示。 |
| 302-1 | 聊天输入框的安全模式；MCP 服务卡片和「工具」权限弹窗 | 核对会话模式的范围说明、MCP 默认策略、例外数和工具范围；权限编辑器应说明保存后生效。 |
| 302-2 | 聊天中的安全审批 | 使用已有策略触发一项安全的测试审批。核对工具、来源、风险、脱敏目标及范围；常见凭据不应出现在审批摘要。核对批准/拒绝、超时文案；Portal 审批列表当前只提供摘要和目标，本次没有扩展原始参数下发。 |
| 402-1 | 设置 → 安全与审计 → 防护概览；技能池导入 | 核对输出脱敏开关、模式、流式脱敏配置、词库、规则与读取时间；点击「运行样例自检」核对实际输出、变化和命中规则。技能导入处显示扫描范围说明。 |
| 402-3 | MCP 服务卡片；防护概览 → 外部服务与端点管控 | 查看远程协议、端点来源与权限摘要。地址仅展示协议、主机及端口，本地进程只展示类型。主机计数和启用状态为配置展示，证书、实际访问和隔离效果另验。 |
| 403 | 设置 → 安全与审计 → 策略审计 | 使用已有策略记录按智能体、工具、决策、时间查询。每页 50 条；CSV 只导出当前显示页。检查无库、旧结构或访问被拒绝时的提示。策略放行不代表执行成功。 |

使用已验证的管理员会话测试安全与审计。Portal 复用现有 SSO 请求和 `7cdf5f1e2` 中的三个 `/api/security/evidence/` 接口；如果当前后端还没有这些接口，须一并提供该兼容版本。已具备接口的环境只需发布本次 Portal 前端。发布前仍应核对候选后端与现场基线的差异，不以整包包含本次前端为由推断后端兼容。

取证应使用真实部署的页面和操作。停止提示只反映本地取消请求，不能证明远程停止或业务回退；脱敏自检使用固定虚构样例，不能证明模型全链路防护；审计页面不新增记录、留存规则或防篡改机制。六个原始条款仍为部分具备。

本地验证：Portal 生产构建和 20 项相关回归测试通过。用 Edge 和虚构接口数据验证了普通聊天停止的三种返回、已生成正文保留、审批脱敏、MCP 摘要、样例自检、审计筛选及导出、403 提示。全量 TypeScript 检查仍有基线已有错误，对照基线未增加诊断。未在 81 或真实 SSO、模型、MCP 环境运行上述验证。
