# dev-81 业务场景发布与 Portal 取证

原件对应位置见[逐项截图索引](dev-81-inspection-evidence.md)。本页只列当前分支可执行的业务场景，以及还不能作为验收证据的部分。受控资料是 Portal 中实际读写和归档纯文本的业务入口，与聊天附件、知识库和既有外部业务数据独立。

## 发布前准备

1. 使用同一 `dev-81` 提交分别构建 Portal 和 QwenPaw 镜像。在独立样品服务与 PVC 上使用不可变镜像标签；保留现有 INOE、模型和 MCP 配置。不要把本页开关直接加到共享生产 release 或旧数据卷。受控资料数据库写入 QwenPaw 的秘密目录，需随 PVC 保留；验证使用合成资料。
2. QwenPaw 设置 `QWENPAW_PRODUCTION_GUARDS=true`、`QWENPAW_SSO_TOKEN_REQUIRED=true`、`QWENPAW_CONTROLLED_DOCUMENTS=true`、`QWENPAW_TRUSTED_CHAT_ISOLATION=true`。如果本次验收范围仅开放文本，另设 `QWENPAW_TRUSTED_CHAT_TEXT_GUARD=true`；它会拒绝聊天附件上传和对话入口的非文本内容块，并对少数明确的越权文本指令拒绝请求。它不扫描图片、音频、视频或附件正文。
3. Portal 设置 `PORTAL_SSO_ENABLED=true`、`PORTAL_PRIVATE_CONVERSATIONS=true`。后一开关停止读写旧的共享浏览器对话缓存，不清除已有内容；取证使用干净浏览器配置。服务端隔离开启后，旧共享会话也不会自动重新归属。验证回退可先关闭新增开关并恢复配对镜像；已保存的资料和审计仍留在样品 PVC。切换开关前另行备份，隔离开启期间创建的聊天不会暴露给旧模式。
4. 准备同一智观认证来源的三个真实账号：普通用户 A、普通用户 B、独立复核员 C。将 C 的稳定用户 ID 加入 `QWENPAW_ADMIN_INOE_USER_IDS`。A/B 用两个浏览器配置分别登录，还应在同一浏览器做退出换人复测。同一账户兼管理员可申请，但不可审批自己的操作。
5. 先用真实环境跑普通聊天、告警分析、资源查询、CMDB、知识库和已启用的定时协同任务。旧版 Skill 管控、数据隔离开关可能改变原现场行为；聊天隔离使用智观用户归属；既有服务型定时任务使用独立任务归属，仍须用真实调度任务复测。发现回归先保留独立样品，避免覆盖现网。

## 现场截图路线

入口是 Portal「设置 → 受控资料」；账号和权限来自后端。每组保留版本、账号、时间、资料/操作编号，以及发起和执行结果。以下同一组操作可用于多个原件位置，但只能证明所述业务范围。

| Word 位置 | Portal 实操与该截的结果 | 覆盖范围 |
| --- | --- | --- |
| 301-1.1/.2、401-2.1/.3 | A 新建聊天与资料。记录资料编号；B 看不到它，手工输入同一编号仍收到拒绝。B 自己的聊天和资料仍可查看。再让 B 尝试打开 C 的复核入口。 | 普通聊天用服务端会话归属；受控资料、操作和授权按主体隔离。旧报表、知识和长期记忆不在此链路。 |
| 301-1.3、402-2.5 | A 保存一份标题不含敏感字样、正文带合成手机号或测试凭据的文档。截分类标签和遮蔽后的预览。尝试未获准下载应拒绝，完成本人确认、C 复核后才能下载一次；截图只显示下载动作和审计结果。 | 内置规则识别有限类型；没有跨业务数据分类，已送到浏览器的内容不能撤回。 |
| 401-2.4/.5、302-2.1/.2 | A 给 B 申请限时共享，确认目标、风险和期限；C 独立批准。A 执行后 B 可读取脱敏预览，但无权导出原文。A 撤销后 B 再读应拒绝。可另做一组一分钟授权，待到期后再读。管理员提交自己的申请时截「本人申请不能自审」。 | 确认和审批是两个已认证主体的服务端操作。此流程不是系统级权限或真实外发审批。 |
| 301-2.1/.2、402-2.1/.2/.3 | A 创建至少 6 份合成文本。先由 C 将单批上限设为 2，A 选择 3 项申请，应被拒绝并提示分批。恢复较高上限后，A 申请归档、确认，C 复核，A 执行。处理中点击暂停，截已归档数、暂停状态和控制耗时；继续后从检查点运行。执行完成后回退，截原资料恢复可读。 | 归档移出可用列表，撤销已有共享，回退只恢复本批资料，不恢复原授权。不涉及永久删除或外部补偿。 |
| 301-2.3、402-2.4 | C 在 A 的归档运行时点击「关停受控资料操作」；截实际暂停计数。A 截暂停和检查点，再截新导出/共享/归档不可用。解除关停后由 A 手工续跑或回退。 | 关停范围仅为受控资料，不代表停止跨智能体、模型或已外发动作。独立物理控制通道、压力及故障注入需另外验证。 |
| 402-1.1/.2 | 开启文本入口守卫。普通业务问题仍提交；另提交明确伪装管理权限或索取受保护配置的合成文本，截 Portal 返回的规则号；C 在操作记录中核对 `chat.input.block`。 | 仅覆盖规则能命中的文本，不等同于全类型、多轮、编码混淆和输出安全。 |
| 403.2 | C 在「复核与管控」改变批量上限或告警阈值；A 操作验证新阈值。C 恢复到变更前策略，截操作人、时间、生效前后值，再由 A 验证旧行为恢复。 | 生效和回退的是本工作区的两项实际运行策略，不代表整个智能体配置均有版本控制。 |
| 403.3/.4/.5、402-2.4 | B 在阈值所设次数内重复读取 A 私有编号；C 截关联事件、账号、时刻和告警。B 截操作已冻结；C 标记处置，B 截已解除并重试自己获准的操作。审计记录不含资料原文或被拦截指令。 | 工作区运行审计和处置；不代表独立归档、防篡改或长期留存。历史全链路仍需现场单独验证。 |
| 301-2.1、403.4、302-1.4/.5、402-3.1 | 另外验证现有 Portal 聊天停止的服务端确认、模型工具调用实际审计，以及 MCP 同一入口的已登记允许/未登记拒绝。 | MCP 正式取证需要现场合法端点、有效证书和准确白名单，不能用配置数量代替真实调用。 |

尚未齐全：真实 SSO 与既有业务数据的全量隔离，跨智能体最小权限委托与完整审计，现有聊天附件、知识库和报告隔离，输入全模态与实际输出全链路、可信引用、真实外部高风险动作确认及追溯、全局运行控制、系统级配置恢复、独立留存、以及端侧适用性。部署、签审材料、持续观测及真实业务指标仍按 Word 原件和实验室确认范围另行取证。不得把本地合成数据截图作为现场正式证据。
