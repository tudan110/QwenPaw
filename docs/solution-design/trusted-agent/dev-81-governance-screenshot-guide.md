# dev-81 可信检验：组件、策略与审计截图指引

本指引对应可信检验原始记录中的以下细项。使用已部署本次前后端版本的 Portal，以有 AI 管理权限的智观账号打开设置和自监控。以下路径不依赖后台 QwenPaw 页面。

| 条款 | Portal 入口与截图操作 | 这张图能说明什么 |
| --- | --- | --- |
| 401-3.1 组件清单 | **设置 → 组件治理与策略 → 组件清单**。切换工作区和类别，截图保留用途、权限、数据范围、风险、版本与来源。对需要补注的组件点 **权限范围 → 按所选条目登记**，填写核实过的范围和风险，回到清单查看「登记」标签。 | Skill、工具、MCP、插件、模型和平台连接器来自现有配置；依赖为 Portal 直接构建声明或后端发行包直接依赖与安装元数据。权限栏包含已有配置和人工补注，不能代替调用验证或完整镜像 SBOM。 |
| 401-3.3 供应链变更 | 在模型配置新增模型或更换默认模型；也可在技能或 MCP 管理做一次实际变更。返回 **设置 → 组件治理与策略 → 供应链变更**，刷新并展开自动记录。 | 证明受管配置实际写入后的记录，含主体、时间、作用域和差异。来源可信度、兼容性、审批和上线仍需独立证据；镜像与依赖的发布变更不在此日志中。 |
| 401-3.4 组件间数据流转 | 打开 **数据流转**，截图保留流向、类型、处理及追溯入口。选同一真实会话或资料操作编号，到链路追踪、工具审计或资料记录取对应证据。 | 页面是部署链路清单，不是动态抓包或全链自动关联。 |
| 401-3.5 漏洞扫描与处置 | 打开 **扫描与处置 → 一键扫描**，截图保留扫描时间和逐项结果；有发现时按建议在原配置或发布入口修正后复扫。 | 「未发现问题」局限于所列检查；「未覆盖 / 检查未完成」不是无漏洞。不会主动访问第三方服务测试漏洞，也不会自动停用组件。 |
| 402-2.5 敏感数据分类与授权 | **设置 → 组件治理与策略 → 敏感数据治理**。先截「敏感分类」和「场景覆盖」，再点 **运行合成样例自检**，截脱敏预览、导出判定和审计批次；可展开「查看各项审计编号」。 | 自检使用服务端固定样本、实际分类与读取/导出校验，以及隔离的授权状态；不生成真实许可、不下载原文。只证明受控资料这一入口，不代表知识库直传、业务导出、对话或日志均已接入。 |
| 402-2.6 敏感数据专项规则 | 在 **敏感数据治理** 底部展开 **采集、留存与删除规则示例（不生效 · 402-2.6）**。切换采集约束、留存天数、脱敏方式或删除规则，点 **应用到示例**。截取「示例输入」「脱敏预览」及规则预览。 | 固定虚构样本可预览打码、移除敏感字段和规则效果；未接入真实数据的采集、过期删除以及服务端日志、缓存和调试处理。 |
| 402-3.3 本地资源访问 | 打开 **本地部署策略**，截取服务端策略和真实检测状态。dev-81 使用远端模型，未启动受管本地推理时保留「未检测到」。 | 策略用于内置 llama.cpp；受管启动或下载在支持 POSIX 权限的宿主执行。外部推理服务、未验证 ACL 的宿主不能冒充受控。 |
| 403.1 链路留痕与异常核查 | **自监控 → 链路追踪 → 选择产生过真实业务调用的会话 → 异常核查**。观察授权结果、工具调用、主体、时间和编号，切换「仅异常」，再点「查看校验依据」。如无异常，使用已实际验证过权限拒绝、工具失败或超时的现有会话；不人为改生产策略凑图。 | 展示实际链路事件；权限拒绝和工具执行结果分别记录。逐跳任务委托、跨智能体授权和数据共享审计仍未接入。 |
| 403.2 配置变更审计 | 在实际入口保存模型、安全规则、提示词或工具配置后打开 **配置变更记录**，刷新并展开记录查看前后摘要。 | 已保存配置的服务端审计，不记录配置原文；不存在历史回填，回退或生效需用原入口及运行记录取证。 |
| 403.3 运行安全监测 | **自监控 → 运行安全**。选择上方时间窗，截取实际后端规则及阈值、工具调用统计。若有真实告警，截取告警编号、触发值、状态及恢复时间；使用 **前往链路异常核查** 查看会话内的授权和调用事实。 | 已接入自监控核心运行告警和工具统计。异常调用、权限拒绝及违规输出的专门门限告警未接入；当前未验证外部通知送达。 |
| 403.5 事件留痕与复盘 | **自监控 → 运行安全 → 在真实告警行点登记事件**，或打开 **自监控 → 事件与复盘** 直接登记实际安全事件、风险测试计划或应急演练计划。使用 **详情** 展示处置、恢复和复盘；未演练的保持「待演练」。 | 可从真实告警带入编号及时间。事件处理和演练结果属于人工登记，有排期不代表演练已完成。 |

仍保留的人工备注（如权限台账）按当前登录账号保存在本浏览器。供应链变更、配置变更和最近一次扫描结果由服务端保存于 `governance/component-governance.db`；该组件证据库不具备独立防篡改或归档能力。直接改文件、CLI 或部署脚本不会自动补录。记录之前请确认依据，不把凭据、用户数据或真实日志原文写入台账。准备截图时可以同一浏览器完成登记与复核；涉及规则生效、漏洞治理、告警送达或演练结论的条款，需要对应生产或受控测试证据。

402-2.5 页面要求 `QWENPAW_CONTROLLED_DOCUMENTS=true` 与 `QWENPAW_PRODUCTION_GUARDS=true`，并以智观 AI 管理员身份访问。若还需要真实业务审批与下载的证据，在测试环境的 **受控资料** 使用一份合成个人信息或商业秘密样本，截取本人脱敏读取、未获许可拒绝、获许可后仅可下载一次的审计。另用合成技术秘密样本取原文禁出证据；不要截原文或放开生产策略。

如允许将 Python 安装包名称与版本发送至 OSV，在后端环境设置 `QWENPAW_GOVERNANCE_OSV_ENABLED=true`；离线或禁止出域时保留默认值，使用另外的离线扫描/镜像 SBOM 证据。远端模型、MCP 及插件的版本漏洞不以本页配置检查结果为准。
