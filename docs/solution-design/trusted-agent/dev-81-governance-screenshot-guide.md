# dev-81 可信检验：组件、策略与审计截图指引

本指引对应可信检验原始记录的九个细项。使用已部署本次前后端版本的 Portal，以有 AI 管理权限的智观账号打开设置和自监控。以下路径不依赖后台 QwenPaw 页面。

| 条款 | Portal 入口与截图操作 | 这张图能说明什么 |
| --- | --- | --- |
| 401-3.1 组件清单 | **设置 → 组件治理与策略 → 组件清单**。切换工作区和类别，截图保留用途、权限、数据范围、风险、版本与来源。对需要补注的组件点 **权限范围 → 按所选条目登记**，填写核实过的范围和风险，回到清单查看「登记」标签。 | Skill、工具、MCP、插件、模型和平台连接器来自现有配置；依赖为 Portal 直接构建声明或后端发行包直接依赖与安装元数据。权限栏包含已有配置和人工补注，不能代替调用验证或完整镜像 SBOM。 |
| 401-3.3 供应链变更 | **组件清单**打开一项组件的 **变更**，进入 **供应链变更**。根据实际工单登记新增、升级、替换或下线、旧新版本、来源、扫描、兼容、审核、回退。保存后点 **详情**。 | 人工核验和变更台账，记录不会触发发布或下线。没有工单时可展示「待核验」流程。 |
| 401-3.5 漏洞扫描与处置 | 在组件清单点 **扫描**，进入 **扫描与处置**。有实际扫描报告时填写组件版本、扫描时间与依据；还未扫描则选「待扫描」。设置复核截止日期，再依据工单登记已停用、隔离、下线或复测；截图保留结果、处置或过期标记。 | 真实扫描以外部报告为准。过期指已登记的复核期过期，页面不会执行扫描、停用或隔离。仅在真实依据存在时登记已完成。 |
| 402-2.6 敏感数据专项规则 | **设置 → 组件治理与策略 → 敏感数据**。切换采集约束、留存天数、脱敏方式或删除规则，点 **应用到示例**。截取前后样例、规则及「只预览，未下发」。 | 固定虚构样本可预览打码、移除敏感字段和规则效果；未接入真实数据的采集、过期删除以及服务端日志、缓存和调试处理。 |
| 402-3.3 本地资源访问 | **设置 → 组件治理与策略 → 本地部署策略**。画面保留「81 验收范围：端侧部署不涉及」，以及模型文件、缓存、本地接口的访问模板。 | 81 的端侧部署按当前样品范围标注不涉及。若纳入本地模型或端侧接口场景，须另外取文件权限、监听范围及鉴权的证据；此处是模板和台账。 |
| 403.1 链路留痕与异常核查 | **自监控 → 链路追踪 → 选择产生过真实业务调用的会话 → 异常核查**。观察授权结果、工具调用、主体、时间和编号，切换「仅异常」，再点「查看校验依据」。如无异常，使用已实际验证过权限拒绝、工具失败或超时的现有会话；不人为改生产策略凑图。 | 展示实际链路事件；权限拒绝和工具执行结果分别记录。逐跳任务委托、跨智能体授权和数据共享审计仍未接入。 |
| 403.2 配置变更审计 | **设置 → 组件治理与策略 → 配置变更记录**。用真实发布或工单登记提示词、安全规则、模型或工具编排的变更主体、前后摘要、生效及回退；打开 **详情** 展示当前记录和修订。 | 可追溯人工台账的内容及修订；未自动审计配置写入。浏览器记录没有防篡改或共享归档能力。 |
| 403.3 运行安全监测 | **自监控 → 运行安全**。选择上方时间窗，截取实际后端规则及阈值、工具调用统计。若有真实告警，截取告警编号、触发值、状态及恢复时间；使用 **前往链路异常核查** 查看会话内的授权和调用事实。 | 已接入自监控核心运行告警和工具统计。异常调用、权限拒绝及违规输出的专门门限告警未接入；当前未验证外部通知送达。 |
| 403.5 事件留痕与复盘 | **自监控 → 运行安全 → 在真实告警行点登记事件**，或打开 **自监控 → 事件与复盘** 直接登记实际安全事件、风险测试计划或应急演练计划。使用 **详情** 展示处置、恢复和复盘；未演练的保持「待演练」。 | 可从真实告警带入编号及时间。事件处理和演练结果属于人工登记，有排期不代表演练已完成。 |

人工台账按当前登录账号保存在本浏览器，没有服务端同步、发布下发和统一归档。记录之前请确认依据，不把凭据、用户数据或真实日志原文写入台账。准备截图时可以同一浏览器完成登记与复核；涉及规则生效、漏洞治理、告警送达或演练结论的条款，需要对应生产或受控测试证据。
