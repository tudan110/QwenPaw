# 可信检验条款取证与适用范围

范围：`dev-81` 企业内网服务端 Portal。编号与原始记录的「检验结果」对齐。此表区分现场证据、代码能力和检验结论；有可操作界面不等于条款全通过。部署相关结论以 81 实际运行配置为准。正式「不涉及」由实验室确认，不勾选尚未验证的结论。

| 条款 | 技术判定 | 可取证位置及缺口 |
| --- | --- | --- |
| 3.2.1-1 / 302-1.1 | 部分；列举的终端系统操作属于不涉及候选 | Portal 主对话的安全审批取业务动作授权证据；静默安装、读其他应用私有数据、修改 OS 安全设置不作为 Portal 功能开放，核验现场后再定适用性。 |
| 3.2.1-2 / 302-1.2 | 宿主机关键进程管理为不涉及候选 | 服务端样品没有提供启停宿主 `init`、`systemd`、安全进程的产品入口。Helm 模板与值文件可核对非 root、禁止提权、移除能力、禁挂服务账号 Token；须用 81 的 Pod 配置、卷挂载、代理/工具清单核对实际范围。对话关停是应用任务中断。 |
| 3.2.1-3 / 302-1.3 | 内核/HAL 直连为不涉及候选 | 画出 Portal → QwenPaw → 已登记智观业务 API / MCP。现场核对无额外宿主硬件设备、特权 sidecar、宿主 API 或驱动通道；普通容器运行依赖 OS 不等于产品开放内核接口。 |
| 3.2.1-4 / 302-1.4 | 涉及，分通道取证 | Portal → MCP 管理 → 已登记服务及工具的允许 / 审批 / 拒绝，配设置 → 安全与审计 → 防护概览中的「验证 MCP 端点准入」。工具风险和接口权限要展示实际记录，现有 MCP 截图不能代替全工具/API 风险清单。 |
| 3.2.1-5 / 302-1.5 | 涉及，分通道取证 | Portal 安全与审计展示已启用的精确端点策略；用「验证 MCP 端点准入」检查实际规则对未登记保留地址的拒绝，无网络调用；业务执行阻断可另查策略审计。登记的智观业务 API 可用作正向对照；未知 MCP 的拒绝不证明所有私有 API 均被拦截。 |
| 3.2.2-1 / 302-2.1 | 已接入真实业务；按范围部分覆盖 | 设置 → 受控资料 → 本人资料脱敏预览 → AI 管理员显式发布 → 知识库检索。知识库永久删除需要 AI 管理员权限、发起预检、短时一次性确认和输入短语；全局禁用时给出拒绝，使用同样有二次确认的归档。个人原件与共享副本分别管理。知识库操作不是删除系统文件或恢复出厂设置。已有独立双人复核的是受控资料敏感导出等场景。 |
| 3.2.2-2 / 302-2.2 | 已覆盖知识库删除及归档，其他操作分别验 | 知识库 → 资料列表 → 删除或归档 → 核对对象 → 查看风险与影响；截图风险等级、资料编号、片段数、影响、取消和确认。取消后原资料仍可检索；确认归档后不可检索。 |
| 3.2.2-3 / 302-2.3 | 支持一类应用安全配置回滚，完整系统范围待证 | 设置 → 受控资料 → 复核与管控 → 策略版本。独立环境修改实际批量上限或告警阈值、验证生效、恢复指定版本再验证。知识库归档后恢复只证明资料可恢复。系统完整配置、数据备份、定期演练还需现场材料。 |
| 3.2.2-4 / 302-2.4 | 已覆盖 Portal 知识库删除、归档；其他通道分别验 | 知识库 → 资料操作记录，截时间、智观 ID、服务进程／PID、资料 ID 与片段数、取消／归档／删除结果。设置 → 安全与审计 → 执行审计另截工具结果；全系统资源访问的覆盖还要核对日志链路。 |

## 81 发布后优先顺序

1. 不调整全局删除保护。用全新合成资料在受控资料发布脱敏版，记录知识库资料编号，测试普通检索与未授权发布拒绝。
2. 用同一资料取「发布 → 命中 → 取消归档仍命中 → 确认后无命中 → 恢复后再次命中 → 操作审计」，优先收齐 3.2.2-1、-2、-4 和 402-1.4。不得用现场真实数据跑永久删除。彻底删除只在允许该操作的隔离样品用临时资料测试。
3. 检查正在运行的 Pod 与运行工具目录，给 3.2.1-2、-3 确认范围；另用现有「MCP 管理」及「安全与审计」为 3.2.1-4、-5 取证。
4. 按实际安全策略变更走一次前态、变更、生效、恢复的完整过程，再填 3.2.2-3；不更动生产阈值只为取图。其余按上表补业务图和独立材料。
