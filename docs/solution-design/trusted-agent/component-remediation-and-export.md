# 组件处置与数据导出

- **扫描处置**：管理员从最新报告中确认停用已安装的工作区技能，或隔离 MCP 连接。处置使用真实启用状态和调用准入规则，不删除文件、凭据或配置。MCP 按连接标识在同一部署生效；若多位数字员工使用同名连接，后续调用一并拒绝。已发送的请求不会被撤回。修复并复扫后，可通过技能管理或调用准入恢复。依赖漏洞和模型接口发现项由对应管理入口处理，不在运行中的服务内自动卸载或切换。
- **业务数据导出**：启用生产保护时，智能体不能借通用报告、Office 生成、文件写入或附件工具绕过确认和计数。告警以及已接入的待办、已办工单共用单次上限，超限明确告知真实条数和上限并记录审计，不强行截断或拆分导出。工单沿用原有授权连接；在总数和完整明细都可核验时，明细短时加密暂存，智能体仅返回本人确认链接。链接 5 分钟有效、仅可下载一次，确认时按当前权限、上限和敏感数据策略复核，下载为 JSON。普通查询不受此导出上限影响。
- **本地部署策略**：可在启动前禁止受管运行，或允许严格受管运行且独立关闭下载。关闭下载后，已缓存且满足安全要求的模型仍能启动。本地接口仅允许本机连接，并验证鉴权。该策略不会修改外部本地提供商和远端模型。
