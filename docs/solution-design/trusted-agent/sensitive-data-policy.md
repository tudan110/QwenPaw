# 敏感数据治理

在 **设置 → 组件治理与策略 → 敏感数据治理**，管理员可以选择内置识别规则、设置自定义敏感字段，并分别为对话输入和模型上下文保存处理方式。策略保存在服务端，作用于同一部署的后续请求，无需重启，也不依赖受控资料开关。两处默认关闭；建议先启用「仅记录命中」，确认业务误报情况后再切换为「阻止发送」。

- **对话输入**：检查普通对话、仅模型对话、后台对话请求的文本输入，以及继续生成使用的问答文本。阻断新消息时不会启动该对话任务。重连不重复检查当时的输入。
- **模型上下文**：在受管聊天模型调用前检查消息文本，包括发给模型的历史消息、系统提示与工具结果；也适用于走同一模型调用链路的后台任务。阻断不等同于撤销此前已进行的工具操作。
- **匹配方式**：内置规则匹配已知号码格式、明确字段和部分凭据格式。自定义规则只保存字段名（例如 `客户编号`），匹配 `客户编号：演示值` 之类的显式字段，不接受正则脚本、不推断语义。请勿把实际敏感值填入规则编辑区。
- **记录方式**：最近命中只显示检查点、时间、动作、规则数量和策略版本，不保存消息正文、命中原值或账号。已保存的规则调整自动进入配置变更记录，审计不公开自定义字段名。

此策略不扫描附件、多媒体、模型回复返回链路、业务导出、日志、缓存或历史落盘内容。它也不替代受控资料原有的分类、脱敏和授权约束。
