# 敏感数据治理

在 **设置 → 组件治理与策略 → 敏感数据治理**，管理员可统一定义敏感数据识别规则，并为每个场景选择「关闭」「仅记录命中」或相应的阻止方式。设置保存在服务端，无需重启，对之后进入相应检查点的操作生效。升级时保留既有对话与模型策略，新接入场景默认关闭；建议先使用「仅记录命中」观察误报，再按需阻止。

| 场景 | 实际生效边界 |
| --- | --- |
| 对话输入 | 受管对话、仅模型对话、后台对话以及继续生成的文本；命中时在派发前阻止。重连不重新提交原输入。 |
| 模型上下文 | 受管模型请求中的提示词、历史消息和工具结果；命中时不发给模型，不撤销之前的工具操作。 |
| 受控资料 | 创建时检查标题和正文，可阻止保存；原有分类、脱敏、限时授权与审批继续独立执行。 |
| 知识库入库 | 文本录入、受控资料发布、元数据编辑及 TXT、Markdown、CSV、TSV 文本上传。阻止模式会拒绝命中或无法检查正文的文件；仅记录模式不拒绝无法检查的格式。 |
| 业务查询与工具结果 | 受管工具的结果以及实时告警、告警台账、关联工单列表。阻止模式先核验完整工具结果，不向对话流式发送未经检查的片段。 |
| 业务与资料导出 | 受控告警明细和受控资料原文。确认后下载仍按当时生效的策略检查，不替代条数上限、身份校验或审批。工单目前仅核验导出条数，不产生文件。 |
| 应用日志 | 检查向应用控制台和滚动日志写出的格式化消息与异常文本；命中时可跳过整条写入。 |
| 运行缓存 | 检查新增的工具原文缓存和对话压缩归档；命中时不写缓存，不改变普通会话历史与模型文件的留存。 |
| 调试与调用追踪 | 检查新增会话和任务追踪，以及调试界面读取的应用日志和追踪；不删除既有记录。 |

- **识别规则**：内置规则匹配已知号码格式、明确字段和部分凭据格式。自定义规则仅保存字段名（例如 `客户编号`），匹配 `客户编号：示例值` 一类的写法；不接受正则脚本，也不推断隐含语义。不要把实际敏感值填入规则编辑区。
- **命中记录**：仅记录场景、时间、动作、命中规则数量和策略版本，不保存命中正文、原值或账号。规则和场景配置变更自动进入配置审计，不公开自定义字段名。
- **范围说明**：这是受管文本入口的策略，不是全盘扫描或数据自动脱敏。不会回溯清理旧数据，不解析图片、音频或视频，不检查模型回复输出链路、通用报告文件、外部业务系统或宿主机/第三方日志。
