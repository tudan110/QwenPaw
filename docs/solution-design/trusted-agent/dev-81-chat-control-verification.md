# 301-2 第 3 至 5 条：Portal 对话控制验证

此记录区分本地自动化验证和待完成的现场验证。未在 81 注入故障，也未完成现场压测。

| 条款 | 本次实现及已做验证 | 现场仍需验证 |
| --- | --- | --- |
| 301-2.3 一键关停 | 仅智观 AI 管理员可在「设置 → 对话」关停。先冻结新请求和续写，再取消当前后端进程所有工作区中经隔离的 Portal 主聊天流。保留最近一批的处理时间、任务编号和实际状态；界面展示计数。重新开启不自动重跑。已保留正文的纯文本回复可在同一会话中手工续写；中止的 CMDB 资产精确查询可手工继续。 | 用两个普通账号及一个管理员验证关停、拒绝新请求、解除及续写。外部工具已经发生的变更、定时任务、独立业务接口和其他副本不在此控制范围。受控资料的回退另行用实际归档场景取证。 |
| 301-2.4 压力及异常 | 本地在两个工作区并发启动 24 条使用模拟阻塞依赖的流，实际取消并确认 24 条。其中一条在关停前主动断开客户端订阅。验证迟迟未清理的任务记为待确认、重复关停不重复生成批次，以及新控制实例仍读取冻结记录。 | 在独立验收样品上测目标峰值并发、实际网络阻断、真实依赖不可用与进程异常。记录条件、发出时刻、处理用时、各终态计数及未确认编号；需同时验证暂停、停止和受控资料回退这几条独立路径。 |
| 301-2.5 降级处置 | 管理控制请求与对话流使用不同 API；在模型依赖等待期间，本地关停仍可执行。应用内单轮运行默认 900 秒，由 `QWENPAW_PORTAL_CHAT_TIMEOUT_SECONDS` 配置；本地用 20 ms 的测试配置验证超时后流关闭、任务清理，并向仍在线的页面发出停止事件。 | 控制仍与对话共用后端进程。进程卡死、网络不可达时的独立运维通道、硬关停以及跨副本编排未验实，不能以本次本地测试替代。 |

冻结标志与最近一次关停批次保存在 `QWENPAW_SECRET_DIR/portal-chat-control/state.json`，不包含聊天正文。用于单后端进程；需保留同一存储目录才能在正常重启后继续冻结。停止后保留本轮提问及已发出的正文，重新打开同一会话可查看。纯文本回复可手动续写；明确的 CMDB 资产精确查询可手动继续，以当前账号权限重新执行该条只读查询。其他工具调用不会被重放。

本地复验：从仓库根目录运行 `python -m pytest -q tests/unit/app/routers/test_portal_chat_control.py tests/unit/app/routers/test_console_text_continuation.py tests/unit/app/routers/test_stopped_portal_turn.py tests/unit/app/test_task_tracker.py tests/unit/app/test_controlled_documents.py`。现场截图只使用实际验证过的对应界面、结果及测试记录。
