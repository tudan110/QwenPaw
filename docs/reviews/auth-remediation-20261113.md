# 智观鉴权 P0 P1 修复记录

本次修复范围为鉴权核验报告中的 AUTH-01 至 AUTH-05：三个 P0 凭据读取入口和两个 P1 业务/退出问题。代码与本地验证完成不等于考试环境已经升级；本次没有推送、部署或轮换真实 INOE 凭据。

## 变更与行为

| 编号 | 修复后的行为 | 验证入口 |
| --- | --- | --- |
| AUTH-01 | `/api/backups` 的列表、详情、导出与写入均纳入管理员策略；关闭普通 SSO 门禁也不会放开匿名管理。管理员导出仍可用，响应禁止缓存 | 实际 Backup 路由的低权限拒绝与管理员 ZIP 下载测试 |

普通智能体发现 `/api/agents` 和原有业务聊天路由继续可用，未把所有 Agent 路径一并封锁。新限制针对完整配置和管理资源。

## 只读业务能力

新增 MCP 声明使用经过核实的完整工具名，覆盖 CMDB 查询、告警、巡检指标、工单查询、资源性能及监控概览。不会因为远端声称 `readOnlyHint` 或名称以 get 开头而授予权限。未评估的工具仍需显式审查；创建工单、CMDB 登录材料等不作为普通只读能力放开。

新增固定 Python `cmdb_read.py` 入口并同步五份受管 CMDB 技能。该入口只允许固定查询路由和既有只读模块，不接受任意目标地址或写方法。技能说明改为通过工具的 `cwd` 参数选目录；不要求 shell 执行位，也不使用 shell 包装器、动态解释器代码或管道。

设备、概览和资源性能技能的受管说明同步采用 `cwd`。工单脚本按 `stats`、`todo-list`、`finished-list`、`detail` 子命令放行，`create` 等操作继续拒绝。POSIX 生产命令以检查过的参数重新引用执行，使带查询参数的字符串保持字面值，避免后续 shell 展开。

巡检查询入口必须显式携带 `--no-notify`，不会把通知推送视为只读；该脚本引用的其他技能依赖树也会校验完整性。

## Console 退出契约

有效本地会话使用 `/api/portal/sso/logout`；过期会话使用 Cookie 清理端点完成清理。客户端校验返回的撤销/清理结果，不把任意 HTTP 200 当作成功。服务不可用时保留重试凭据并提示退出未完成。

退出落地页使用不含凭据的 `signed_out=1` 标记，阻止引导流程立即用仍有效的 INOE 登录 Cookie 再次登录；用户点击“重新登录”后才恢复 SSO 引导。这是应用退出，不宣称 INOE 全局注销。原生密码账户设置入口在 SSO 模式隐藏。
