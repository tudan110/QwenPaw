# 生产模式技能兼容修复（2026-11-19）

本次完善非日志技能执行入口。日志查询、安全扫描、隐患检测及其后端适配不在本次范围内。

## 权限与功能

| 场景 | 生产模式执行方式 | 人工确认 |
| --- | --- | --- |
| 知识检索、页面导航、专线查询、告警分类统计、根因评分 | 固定脚本、参数契约及整项技能完整性校验 | 不额外要求管理员；仍遵守工作区治理策略 |
| Web 监测列表、详情、历史运行 | 6 个明确的只读 MCP 工具或受管脚本；ID 不允许路径和查询串 | 同上 |
| CMDB Excel/CSV 等文件解析与预览 | 先用 `write_skill_context` 准备上下文，再执行桥接脚本 | 预览不写 CMDB；正式导入必须管理员审批 |
| 告警报告回传、页面操作指令、Web 新增/修改/触发/删除 | 固定脚本入口，展示操作与参数 | 必须可信管理员审批，前端操作卡片仍保留原有确认 |
| cron、会话管理、频道消息 | 受限 `qwenpaw`/`copaw` CLI，当前 `--agent-id` 和明确目标 | 必须管理员审批；列表/详情接口未隔离会话所有者，读取暂不自动放行 |
| Office 及 JSON 准备 | `process_office_document`、`write_skill_context` 结构化工具 | 生成新产物；不授予通用脚本或文件覆盖权限 |
| FDE 构建 | 静态检查、列表和预览可用；生成、删除 staged 产物及创建智能体走固定动作 | 写动作必须管理员审批；动态 `probe` 尚无真实隔离，仍不可用于生产对话 |

“无需额外管理员审批”只说明生产边界分类；代理自身的禁用、沙箱或人工确认规则仍然生效。
当前 Web MCP 写接口保留连接器的原有限制，不能通过切换通道绕过。

## 输入和审批约束

- JSON 上下文最大 256 KiB，仅在当前工作区 `artifacts/skill-context` 下新建 UUID 文件，不接受输出路径或覆盖。
- CMDB 附件限当前工作区、最多 20 个/合计 50 MiB；保持 Excel、CSV、TSV、JSON、文本、Word 和图片等输入路径，正式导入前展示预览。
- 审批绑定命令、参数、JSON 和嵌套附件的内容摘要；内容变化、身份过期、调用重放均不能复用授权。FDE 删除还绑定真实目标目录及其文件清单。
- 不接受自定义服务地址、凭据参数、未知/缩写参数、符号链接或跨工作区文件。受管技能被修改后需走维护发布流程，不能临时信任同名脚本。
- 请求身份传到门户子进程和 CMDB 客户端；缺失或失效时不借用共享账号。元数据缓存按连接和身份摘要隔离，不保存原始 token，并清理旧格式缓存。

## Office 支持范围

- 支持 DOCX/XLSX/PPTX 文本与表格读取、新建 Word 和 Excel、纯值 Excel 单元格修改，以及 Word/PPT 同一文本片段内的替换。原文件保留，新文件写入 `artifacts/office`，使用 `send_file_to_user` 交付。
- `export_report` 默认导出 PDF，也支持 Word；Office 文件的 `export_pdf` 提取文本后重新排版，不保留原始版式。
- 单文件限 10 MB、解压合计 50 MB、最多 2000 个压缩条目；Excel 最多 50 张表、20000 个单元格，文本或操作参数最多 100000 字符。输入与输出均拒绝符号链接及目录替换绕过。
- 不执行宏、外部链接、嵌入对象或公式。已有公式只可作为文本读取，含公式工作簿不能编辑；暂不支持新建 PPT、复杂版式编辑、修订、公式计算及高级 PDF 合并/OCR/表单处理。

## 保留限制与交付

通用 Office Python、任意 shell、FDE 动态试跑和 Web 任意 URL 选择器探测仍不开放。Himalaya 邮件需要部署额外二进制与连接配置；自定义插件脚本须独立纳入可信入口。本次不将这些场景标记为已验证可用。

发布时同时交付后端工具代码、内置技能文档和重建后的 universal seed；仅更新技能 Markdown 不能启用新工具。上线后还需使用真实登录身份复验下载、业务查询和审批，不能以本地测试代替生产验收。
