# 生产协同与只读搜索兼容修复

## 范围

本版优先修复开启 SSO 和生产守卫时，自动 cron 缺少请求身份导致跨 Agent 协同失败的问题，以及普通用户无法使用文件只读搜索的问题。不关闭鉴权，不将共享 INOE 业务 token 作为本机管理员登录凭证。

## 协同身份

服务器在自动 cron 执行期间签发短时协同凭证；任务正文中的 `source`、`user_id` 不作为可信身份。调度器显式区分自动与手动触发，自动任务不继承调度线程可能残留的个人身份。凭证仅允许智能体发现、聊天、异步任务提交和结果查询，不提供配置管理、上传、fork 或通用管理权限。在线请求及登录后手动触发的任务继续使用已验证用户身份。

凭证仅向可信 API 地址转发，存储哈希及到期时间，任务结束或异常退出后撤销。调用方应在 cron 执行期间等待异步协同完成；凭证不是独立后台任务的长期登录凭据。业务查询仍使用既有后台业务凭证配置，其上游数据权限取决于配置账号，协同身份本身不授予 INOE 权限。

原生协同工具直接传递当前执行上下文。通过 shell 调用协同 CLI 时，严格沙箱的环境变量白名单需显式允许 `QWENPAW_REQUEST_COLLABORATION_TOKEN`；已有空值遮蔽仍然生效。不要把临时凭证手工写入部署配置。

## 只读搜索

普通用户可使用 `grep_search` 和 `glob_search` 搜索当前智能体工作区。检查覆盖搜索根目录和每个递归项，拒绝越界路径、符号链接、秘密目录及 `.env`、`.env.*` 等敏感配置。关闭生产守卫时保留原有搜索行为。这是应用层访问保护，不替代操作系统沙箱。

## 发布验收

1. 保持 `QWENPAW_SSO_TOKEN_REQUIRED=true` 和生产守卫开启，使用干净启动后的自动调度任务调用 `list_agents`、`chat_with_agent`，以及提交并等待异步协同结果。
2. 对比登录后的手动触发与自动调度；确认没有缺少凭证的 401，且业务返回内容正常。
3. 确认过期、伪造和已撤销协同凭证被拒绝，协同凭证不能访问管理接口；正常用户的在线协同仍沿用自身权限。
4. 用普通用户搜索工作区业务文件，确认可返回结果；秘密配置、工作区外路径和符号链接不能借搜索泄漏。

## 尚未覆盖

本版不恢复通用 cron CLI 和任意 Office/PDF 脚本执行；报告仍通过受控 `export_report` 导出 PDF、DOCX、Markdown。fork 创建和清理仍受管理权限约束，不属于后台协同凭证范围。技能目录污染、历史临时脚本和完整性阻断需按已有审核隔离流程处理。MCP 继续使用其配置凭证；其他无 HTTP 上下文的后台入口不自动获得 cron 凭证。本地验证不能替代实际生产镜像、PVC、SSO 和上游业务权限的验收。
