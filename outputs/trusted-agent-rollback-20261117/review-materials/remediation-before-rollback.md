## 配置和操作

- 既有管理员访问 `GET /api/security/control` 获取 `epoch`。
- `POST /api/security/control/freeze`：`{"expected_epoch":0,"reason":"事件处置"}`。先持久冻结再请求取消。重复/并发的旧版本返回 409。
- `POST /api/security/control/unfreeze` 使用当前版本和处置说明显式解除。解除不会复活旧审批或自动重放旧任务。
- `GET /api/security/control/tasks/{run_key}?namespace=...` 查询实际本地控制状态；`GET /api/security/control/audit-status` 查询归档队列。
- `QWENPAW_MCP_ALLOWED_URLS`：JSON 字符串数组，填写实际 MCP 初始端点。旧 `MCP_ALLOWED_HOSTS` 不再授予整台主机访问。
- `QWENPAW_EGRESS_RULES`：JSON 数组，每项形如 `{"url":"https://model.example/v1/chat/completions","methods":["POST"],"networks":["192.0.2.0/24"]}`。示例是文档保留地址，必须替换为实际服务和网络。MCP 的 SSE 入口及消息回传路径分别登记，动态会话查询参数不改变路径授权。
- `QWENPAW_AUDIT_ARCHIVE_URL`：独立 HTTPS 收集端；`QWENPAW_AUDIT_ARCHIVE_TOKEN` 从 Secret 注入。收集端持久提交后返回 `{"event_id":"...","sha256":"..."}`，不得仅回 HTTP 200。
- `QWENPAW_AUDIT_MAX_PENDING` 默认 100000；达到队列上限拒绝新工具执行。`QWENPAW_OUTPUT_MAX_BYTES` 默认 8388608。
- 新控制数据保存在工作目录 `trusted-agent/control.db`，工具禁止直接读取、编辑。需持久卷随应用重启保留；整卷丢失/回滚的恢复策略需现场演练。

安全网络配置默认拒绝。部署前必须按真实端点补齐规则，不能通过关闭生产守护恢复连通。本次未推送、部署、轮换现场凭据，也未操作现有未提交的大屏工作。

Console 的“设置 → 安全 → 执行控制与归档”提供冻结/解冻、当前控制版本和积压查询。停止链路会等待真实执行子任务的清理，不再先把外部占位任务标为完成。附件下载使用受控客户端和临时文件，成功后才替换目标；32 MiB 上限、目录穿越检查及生产解析失败阻断一起生效。运行时增加外部资料不得改变权限与任务的固定提示，但不把提示词本身当作完整的注入防御。

## 组件与验收工具

`scripts/trusted-agent/component_inventory.py --output <路径>` 从执行它的 Python 环境和 Console/Portal npm 锁文件生成 CycloneDX JSON。它不查询外网，不读取运行凭据；OS 包、最终镜像、远程 MCP/模型仍需另行盘点。此清单不等同漏洞扫描或正式交付锁文件。发布前须对固定镜像 digest 和该 SBOM 使用企业批准的 Trivy/Syft/pip-audit 等扫描器，保存数据库版本、原报告、例外和复扫结果；不得用本机开发环境结果替代镜像结论。

`scripts/trusted-agent/run_acceptance.py --cases <JSONL> --output <JSON>` 默认只校验用例，不发请求。显式加 `--execute --base-url <隔离验收环境>` 才执行；凭据从 `QWENPAW_EVAL_ACCESS_TOKEN` 环境变量读取。只允许已列出的只读业务 POST，拒绝管理/写操作。每条用例包含 `id/path/method/body`，可提供非空 `expected_json` 作为业务后置条件子集；无金标标为未评判。输出完整请求耗时、HTTP 成功吞吐、明确判定的任务数与通过数，逐请求记录写 JSONL，不保留响应正文和凭据。超过 50000 次请求的分位数使用水库采样，原始耗时仍可离线重算。首字时延、主机资源、真实业务准确率标注及不少于 72 小时观测仍需专项记录。
