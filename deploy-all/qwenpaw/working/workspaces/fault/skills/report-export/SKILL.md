# 报告导出与下载

把报告文件归档到平台统一的下载目录（`<working_dir>/extensions/reports/<agent_id>/`），
并输出 portal 可渲染成下载按钮的 markdown 链接。

## 触发边界（故障工作区）

- 「分析这条告警」「生成告警分析报告」「完成分析并推送通知」没有要求文件时，不调用本技能，不创建临时报告文件，按 `alarm-analyst` 输出完整聊天卡片。
- 明确要求下载、导出、保存为文件，或明确文件格式交付时才使用；回读失败、沙箱不可用、报告过长不是改走导出的理由。
- 同轮分析并导出：聊天中仍输出完整卡片报告，下载链接只作补充，放在报告的「追溯、复核与按需导出」节，总结仍以通知状态结束。
- 后续仅导出已有报告：复用原正文并返回真实链接，不重查数据、不重新分析、不重新通知。归档文件不是通知发送凭据。

## 工作流程

1. **撰写报告内容**（基于当前会话上下文，不要凭空编造数据）：
   - 默认格式 **Markdown**：把报告内容写入当前目录的临时文件，如 `./_report_tmp.md`
   - 用户要 PDF → 用 **pdf** 技能生成 `.pdf` 文件
   - 用户要 Word → 用 **docx** 技能生成 `.docx` 文件
   - 用户要 Excel 报表 → 用 **xlsx** 技能生成 `.xlsx` 文件
   - 用户要 PPT → 用 **pptx** 技能生成 `.pptx` 文件
2. **归档**（在工作区目录下执行；`{this_skill_dir}` 指本技能目录）：

   ```bash
   python {this_skill_dir}/scripts/save_report.py <生成的文件路径> --title <报告主题> --copy
   ```

3. **回复用户**：脚本最后会输出一行 `[下载报告：...](...)` 形式的 markdown
   下载链接，原样包含在回复中，portal会渲染成下载按钮。同轮告警分析时把链接放在完整报告的追溯节，不能只回复链接或通知文案；后续单独导出请求可直接返回链接。

## 注意

- `--title` 用简短中文主题词（如 `数据库巡检报告`），不要带路径、斜杠或扩展名。
- 不要自己拼下载链接，一律以脚本输出为准。
- 脚本默认移动源文件，本工作区导出使用 `--copy` 保留原报告，不覆盖或移动原始证据。
- 支持的格式：`.md` `.pdf` `.docx` `.xlsx` `.pptx`，其余格式脚本会拒绝。
